[![Build & Upload](https://github.com/hep-forge/mcfm-feedstock/actions/workflows/autoupload.yml/badge.svg)](https://github.com/hep-forge/mcfm-feedstock/actions/workflows/autoupload.yml)

[![Anaconda Platforms](https://anaconda.org/hep-forge/mcfm/badges/platforms.svg)](https://anaconda.org/hep-forge/mcfm)

Feedstock for [mcfm](https://mcfm.fnal.gov) — part of [hep-forge](https://anaconda.org/hep-forge).
Builds linux-amd64 + linux-arm64 in one matrix workflow and uploads to the
[hep-forge](https://anaconda.org/hep-forge) Anaconda channel.

MCFM is a parton-level Monte Carlo program

## Install

```bash
conda install -c hep-forge -c conda-forge mcfm
```
