# mcfm-feedstock

[![Build AMD64](https://github.com/hep-forge/mcfm-feedstock/actions/workflows/autoupload.amd64.yml/badge.svg)](https://github.com/hep-forge/mcfm-feedstock/actions/workflows/autoupload.amd64.yml)
[![Build ARM64](https://github.com/hep-forge/mcfm-feedstock/actions/workflows/autoupload.arm64.yml/badge.svg)](https://github.com/hep-forge/mcfm-feedstock/actions/workflows/autoupload.arm64.yml)

Feedstock for [mcfm](https://mcfm.fnal.gov) — part of [hep-forge](https://anaconda.org/hep-forge).

MCFM is a parton-level Monte Carlo program

## Install

```bash
conda install -c hep-forge -c conda-forge mcfm
```
